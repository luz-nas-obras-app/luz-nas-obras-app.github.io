# Luz nas Obras - Landing Page

Pagina publica do aplicativo gratuito Luz nas Obras, dedicada a apresentar o estudo
Espirita-Cristao e encaminhar o estudante para o aplicativo.

Publicacao atual: https://luz-nas-obras-app.github.io/luz-nas-obras.github.io/

Aplicativo: https://luz-nas-obras.vercel.app/

## Visualizacao local

O projeto e estatico. Abra `index.html` no navegador ou use um servidor local simples.

Arquivos principais:

- `index.html`: apresentacao publica do projeto.
- `manual.html`: manual basico do estudante.
- `social-preview.png`: imagem social usada em compartilhamentos.

## Publicacao no GitHub Pages

Suba este conteudo para o repositorio do GitHub Pages e configure a publicacao pela
branch principal. Como o projeto nao possui build, o deploy pode apontar direto para
a raiz do repositorio.

## Pendencias institucionais

- Adicionar os links institucionais de contato e politica de privacidade quando aprovados.
- Confirmar o repositorio final de publicacao antes do primeiro push oficial.
